Политика в отношении обработки персональных данных

Эта политика относится к сайту vneshablona.ru и заявкам, которые посетители отправляют через его форму.

1. Кто обрабатывает данные

Оператор персональных данных — Якунин Олег. По вопросам обработки данных можно написать на oleg.kemz@gmail.com.

2. Какие данные и зачем нужны

Форма собирает ваше имя, контакт для ответа, описание задачи и, если вы его указали, название компании. Эти сведения нужны, чтобы получить обращение, связаться с вами, обсудить проект и подготовить предложение по вашему запросу.

При отправке запроса технически обрабатывается IP-адрес для ограничения частоты заявок и защиты формы от массовой отправки. Не указывайте в свободном поле сведения о здоровье, убеждениях, биометрические данные и данные других людей, если для этого нет законного основания.

3. На каком основании

Данные из формы обрабатываются на основании вашего отдельного согласия, которое вы даёте, установив отметку перед отправкой заявки. Для подготовки договора по вашей инициативе и исполнения требований закона могут применяться также основания, предусмотренные Федеральным законом № 152-ФЗ «О персональных данных».

4. Как проходит заявка

После отправки данные передаются по защищённому соединению на API сайта jakuninoleg.dev, которым пользуется тот же оператор. Для доставки письма с заявкой на контактный адрес оператора используется сервис электронной почты Resend. По информации Resend, содержимое отправленных писем хранится в США. Это означает передачу сведений из заявки за пределы России.

Доступ к обращению нужен для ответа вам и обсуждения проекта. Данные не публикуются и не используются для рекламной рассылки по этой форме. Обработка может включать получение, запись, хранение, уточнение, использование, передачу для доставки письма, удаление и уничтожение данных, с применением автоматизированных средств и без них.

5. Как долго хранятся сведения

Данные обрабатываются до достижения цели обращения или отзыва согласия, если закон либо договор не требует продолжить их хранение. После этого оператор прекращает обработку и удаляет данные в сроки, установленные законодательством.

6. Защита данных и ваши права

Заявка передаётся в API через HTTPS. API ограничивает число отправок с одного IP-адреса. Оператор принимает правовые, организационные и технические меры для защиты данных от неправомерного доступа, изменения, раскрытия и утраты. Вы можете запросить сведения об обработке ваших данных, попросить их уточнить, заблокировать или удалить, а также отозвать согласие.

Для этого напишите на oleg.kemz@gmail.com и укажите контакт, по которому вы отправляли заявку. Оператор рассмотрит обращение в порядке, предусмотренном законодательством.

7. Актуальная редакция

Действующая редакция политики всегда доступна на этой странице. При изменении порядка обработки здесь будет опубликована новая версия с датой её вступления в силу.

Согласие на обработку персональных данных

Отдельный документ для формы заявки на сайте vneshablona.ru. Галочка рядом с формой не установлена заранее: решение остаётся за вами.

1. Кому и для чего даётся согласие

Отправляя форму с установленной отметкой, я свободно, своей волей и в своём интересе даю Якунину Олегу согласие на обработку указанных мной данных, чтобы он получил моё обращение, связался со мной, обсудил задачу и подготовил предложение о сотрудничестве.

2. Состав данных

Согласие относится к моему имени, адресу электронной почты, номеру телефона или контакту в мессенджере, названию компании (если указано) и сведениям, которые я сам(а) внесу в описание задачи. Технический IP-адрес может кратковременно использоваться для защиты формы от массовой отправки.

3. Действия и способ обработки

Я соглашаюсь на сбор, запись, хранение, уточнение, использование, передачу для доставки письма, блокирование, удаление и уничтожение данных автоматизированным способом и без него. Заявка проходит через API jakuninoleg.dev; для отправки письма используется Resend, который хранит содержимое писем в США. Согласие не распространяется на рекламные рассылки или публикацию моих данных.

4. Срок и отзыв

Согласие действует до достижения целей обработки или моего отзыва, если нет другого законного основания для продолжения обработки. Я могу в любой момент отозвать его письмом на oleg.kemz@gmail.com, указав контакт, использованный в заявке. Отзыв не отменяет законность обработки до его получения.

5. Как подтверждается согласие

Согласие предоставляется отдельной отметкой в форме и отправкой заявки. Вместе с заявкой оператор получает запись о факте согласия, редакции этого документа и времени отправки. До отправки можно ознакомиться с политикой обработки данных.
